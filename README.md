# Company Profile Jakarta Vet

## Teknologi
- Laravel 12
- MySQL
- Bootstrap

## Cara Instalasi

1. Clone repository

git clone https://github.com/necromantichrist/company-profile-jakarta-vet.git

2. Install dependency

composer install
npm install

3. Copy file environment

cp .env.example .env

4. Generate key

php artisan key:generate

5. Konfigurasi database pada file .env

6. Jalankan migration

php artisan migrate

7. Jalankan aplikasi

php artisan serve
